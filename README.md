# CodingShuttle Focus Mode 🎯

> Distraction-free learning extension for [codingshuttle.com](https://www.codingshuttle.com).  
> **GitHub:** [https://github.com/bobby-99/codingshuttle-focus-mode](https://github.com/bobby-99/codingshuttle-focus-mode)

Removes marketing ads, sticky navbars, and floating widgets while adding essential learning tools (highlighter, notes, Pomodoro, reading progress, and quick-jump TOC).

---

## ⚡ Highlights

- **Ad & Distraction Blocker**: Hides top navbar, promo cards, WhatsApp widget, banners, and right-column ads. Dynamically auto-expands the reading view.
- **Reading Suite**: Top reading progress bar, estimated read time, and spotlight focus mode (dims everything except hovered paragraph).
- **Active Learning**: 4-color persistent highlighter, inline margin notes (📝), one-click code copy, auto-generated floating TOC, and lesson completion checkmarks (✅).
- **Pomodoro Timer**: Built-in 25-minute study HUD with timer controls and completion alerts.

---

## 🚀 Quick Setup

1. **Clone the repo:**
   ```bash
   git clone https://github.com/bobby-99/codingshuttle-focus-mode.git
   ```
2. In Chrome, Chromium, Helium, Brave, or Edge, visit `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the `codingshuttle-focus-mode` folder.
5. Open any handbook page on [codingshuttle.com](https://www.codingshuttle.com).

---

## 💻 Compatibility

- Manifest V3 compliant.
- Works across **Windows, macOS, and Linux** (Chrome, Chromium, Helium, Brave, Edge).
- 100% local — zero dependencies, uses `chrome.storage.local`.
